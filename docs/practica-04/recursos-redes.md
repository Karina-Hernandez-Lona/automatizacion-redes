Recursos técnicos consultados

Recurso 1

Nombre: Documentación oficial de GNS3.
URL: https://docs.gns3.com/
Tema que aborda: Instalación, configuración y simulación de redes.
Tipo de información que ofrece: Guías, documentación técnica e instrucciones de configuración.
Utilidad para el proyecto integrador: Ayuda a comprender y solucionar problemas relacionados con la infraestructura de red simulada.
Ejemplo de una situación en la que lo consultaría: Cuando una conexión entre dispositivos no funcione correctamente en una topología.

Recurso 2

Nombre: Netmiko.
URL: https://github.com/ktbyers/netmiko
Tema que aborda: Automatización de conexiones de administración con dispositivos de red compatibles.
Tipo de información que ofrece: Código fuente, instrucciones de instalación, ejemplos y registro de cambios.
Utilidad para el proyecto integrador: Permite investigar cómo automatizar tareas de administración de dispositivos de red.
Ejemplo de una situación en la que lo consultaría: Cuando necesite conocer cómo establecer una conexión SSH con un dispositivo compatible.

Recurso 3

Nombre: Documentación oficial de Python.
URL: https://docs.python.org/3/
Tema que aborda: Programación en Python y biblioteca estándar.
Tipo de información que ofrece: Manuales, referencias y ejemplos.
Utilidad para el proyecto integrador: Ayuda a desarrollar y corregir los scripts utilizados para administrar información de dispositivos.
Ejemplo de una situación en la que lo consultaría: Cuando necesite recorrer un diccionario para localizar un dispositivo por su nombre.
