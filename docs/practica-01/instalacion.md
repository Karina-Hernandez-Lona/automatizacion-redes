# Práctica 01: Instalación del entorno

## Objetivo
Preparar el entorno de programación para desarrollar proyectos de automatización de redes.

## Herramientas instaladas

### 1. Python
Se instaló Python 3 y se verificó su funcionamiento mediante el comando:

python --version

### 2. Visual Studio Code
Se configuró Visual Studio Code y se instaló la extensión oficial de Python de Microsoft.

### 3. Git
Se instaló Git para gestionar el control de versiones del proyecto.

Versión instalada: 2.55.0.windows.5

Comando de verificación:

git --version
